# 🎓 Courses

My KFUPM coursework, one folder per term (KFUPM term codes, e.g. `261`), then one folder per course.

| Term | Courses |
| --- | --- |
| 261 | [MATH 102](<261/MATH 102/MATH 102.md>) · [ICS 202](<261/ICS 202/ICS 202.md>) · [ICS 253](<261/ICS 253/ICS 253.md>) · [DATA 211](<261/DATA 211/DATA 211.md>) · [ENGL 102](<261/ENGL 102/ENGL 102.md>) |

Each course folder has a course page (same name as the folder) plus `Notes/`, `Assignments/` and `Exams/`.

## Adding a course
1. Make the folder `<term>/<COURSE CODE>/`, e.g. `262/MATH 201/`.
2. Inside it, create the course page from the *Course* template, named exactly like the folder.
3. Add `Notes/`, `Assignments/`, `Exams/` as you need them.
