# Adib's Mind

My second brain: an [Obsidian](https://obsidian.md) vault for what I learn and build — KFUPM courses, mathematics, coding and machine learning.
Everything is plain Markdown with LaTeX, so it reads on GitHub as well as in Obsidian.

| Folder | What's inside |
| --- | --- |
| [Courses](<2 Create/Courses/Courses.md>) | KFUPM coursework by term (term codes, e.g. `261`) and course: notes, assignments, exams |
| [Math](<2 Create/Math/Math.md>) | Problem sets with full solutions — [Calculus](<2 Create/Math/Calculus/Calculus.md>) (Larson & Edwards, 7th ed.), CH01 – CH16 |
| [Coding](<2 Create/Coding/Coding.md>) | [LeetCode](<2 Create/Coding/LeetCode/LeetCode.md>) write-ups and coding notes · code projects live in [code-lab](https://github.com/adib-alqurashi/code-lab) |
| [ML](<2 Create/ML/ML.md>) | Self-study: ML maths, ML, deep learning, LLMs, generative AI |
| [Projects](<2 Create/Projects/>) | Project research and design notes |
| [3 System](<3 System/>) | Templates and attachments |

`1 Organize` (tasks, calendar, habits, daily notes) is my private planner. It lives in the same vault on my computer but is not part of this repository.

## Conventions
- **Maths:** one file per section (`8.2.md`); each problem as **Problem → Idea → Solution → Takeaway**.
- **LeetCode:** one note per problem (`0001 Two Sum.md`) with difficulty, pattern, idea, solution, complexity and takeaway.
- **Courses:** `<term>/<COURSE CODE>/`, with a course page of the same name.

## Opening it in Obsidian
Clone the repo and open the folder as a vault. Community plugins used: Dataview, Tasks, Full Calendar, Habit Tracker 21, Git.
